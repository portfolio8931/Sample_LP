# Sample_LP

## 概要
企業の社長インタビュー、メンバー紹介、ビジョンなどを掲載したコーポレートLP（ランディングページ）です。  
会社の魅力や雰囲気が訪問者に伝わる構成・デザインを意識して制作しました。

* **公開URL**: https://sample-lp-tawny.vercel.app/

## 利用技術
* **HTML (EJS)**: コンポーネント化やコードの共通化を実施
* **CSS (SCSS)**: ネストや変数を活用して保守性の高いCSSを設計
* **JavaScript (jQuery)**: slickを利用した動的コンテンツの実装
* **パッケージマネージャー**: Yarn
* **ホスティング**: Vercel

## 実装のこだわり
* **レスポンシブ対応**
  * PC・スマートフォンなど、デバイスの画面サイズに合わせたレイアウト調整を徹底しました。
* **画面サイズに応じたCSSアニメーション**
  * デバイスの画面サイズ変更に応じた演出・アニメーションを実装しました。
* **EJSによる効率的なモジュール化**
  * ヘッダーやフッターなどの共通パーツをコンポーネント化し、コードの再利用性とメンテナンス性を重視しました。

## セットアップ手順

### 動作環境
* Node.js
* Yarn

### 手順
1. リポジトリをクローンします。
   ```bash
   git clone https://github.com/portfolio8931/Sample_LP.git
   cd Sample_LP
2. 依存パッケージをインストール、開発用サーバー（ローカル環境）を起動します。
   ```bash
   yarn install
   yarn start
3. EJSとSCSSをビルドする場合（public/ 配下にファイルを生成）
   ```bash
   yarn build
